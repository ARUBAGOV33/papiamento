## Rule

Stilistica describes pleonasm as using more words than are needed to express a concept. It says that, used well, a pleonasm stresses a characteristic of the concept.

## Source

Stilistica di Papiamento (2008), §2 "Formulacion corecto", point 3 "Pleonasmo", PDF page 2.

## Correct

- beton shinishi, sneeuw blanco, sanger cora

## Notes

- STI2008 has no printed page numbers; "2" is the PDF page.
- In each example the adjective names a property the noun already has (grey concrete, white snow, red blood).
- sneeuw is copied as printed. It is an AB 2018 word (word list p. 62) and a loan that keeps its Dutch spelling (AB 2018 §12.2, exception list a, p. 43; `lexicon/loanwords/loanwords.tsv`, loan-0196).
- The page does not say a pleonasm should be removed, so nothing is flagged.
- The old rule pack also had RULE_STY_PLEO_002 (allow pleonasm for emphasis), which is the second sentence of this same point and is covered here, and RULE_STY_PLEO_003 (prefer the shorter phrase), which the page does not state.
- STI2008 is restricted: the wording is restated; one example line is quoted.
