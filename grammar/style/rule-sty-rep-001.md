## Rule

Stilistica advises avoiding repetition that serves no purpose. It explains this as not using words only to fill space (it calls them stopwoordjes), and names pues and mas bien as examples.

## Source

Stilistica di Papiamento (2008), §2 "Formulacion corecto", point 1 "Ripiticion", PDF page 2. Example line: "pues, mas bien, etc."

## Notes

- STI2008 has no printed page numbers; "2" is the PDF page.
- pues is a valid word (AB 2018 word list, p. 54). The advice is against using such words only as filler, not against the words themselves. The page gives no replacement and no fuller list of filler words, so nothing is listed under Incorrect; a checker would need its own curated list.
- The advice follows the remark that repetition across a few successive sentences can also add emphasis. Emphatic repetition is RULE_STY_REP_002.
- stopwoordjes is the Dutch term the page uses; the AB 2018 word list has stopwoord (p. 64).
- The old rule pack split this point into RULE_STY_REP_001 (unneeded repetition), RULE_STY_REP_003 (filler words) and RULE_STY_REP_004 (repeated function words). REP_003 is the same statement and is covered here; REP_004 is not on the page.
- STI2008 is restricted: the wording is restated; one example line is quoted.
