## Rule

Stilistica describes tautology as using two words with the same meaning together, and says that it, too, serves to add emphasis. The page does not call it an error.

## Source

Stilistica di Papiamento (2008), §2 "Formulacion corecto", point 2 "Tautologia", PDF page 2.

## Correct

- Hamas y nunca semper y cuando.

## Notes

- STI2008 has no printed page numbers; "2" is the PDF page.
- hamas and nunca both mean "never" (`_meta/invariants.md`, ruling 2026-10-16).
- The page prints two more examples on separate lines; only one line is quoted because STI2008 is restricted.
- The old rule pack also had RULE_STY_TAUT_001, which flags synonym pairs as a warning. The page presents tautology only as a device for emphasis, so that rule was not written, and this one flags nothing.
