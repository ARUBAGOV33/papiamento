## Rule

Stilistica says symmetry also matters in an enumeration: its parts should be of the same kind.

## Source

Stilistica di Papiamento (2008), §2 "Formulacion corecto", point 10 "Simetria/Asimetria", PDF page 4.

## Correct

- Mi ta sufri di reumatismo y (di) presion halto.

## Exceptions

- A footnote on the same page says the mismatched version can be funny in a recreational text.

## Notes

- STI2008 has no printed page numbers; "4" is the PDF page.
- The page's incorrect example keeps the first item but makes the second one an annoying neighbour instead of an illness. No corrected version of it is printed, and only one line is quoted because STI2008 is restricted.
- §4 "Idioma figurativo", point 9 "asimetria" (PDF page 8) lists the same effect, putting together things that have nothing to do with each other, as a figure of speech.
- The old rule pack's RULE_STY_ASYM_003 (unbalanced coordinated phrases) restates this rule and is covered here.
- Pronoun consistency, from the same point: RULE_STY_ASYM_001.
