## Rule

Stilistica describes repetition as using the same word twice in one sentence to draw attention or to add emphasis. It adds that repetition across a few successive sentences can do the same.

## Source

Stilistica di Papiamento (2008), §2 "Formulacion corecto", point 1 "Ripiticion", PDF page 2.

## Correct

- “Placa, placa ta tur cos!”

## Notes

- STI2008 has no printed page numbers; "2" is the PDF page.
- Emphatic repetition is a stylistic device, so nothing is flagged by this rule. Repetition without a purpose is RULE_STY_REP_001.
- STI2008 is restricted: the wording is restated; one example line is quoted.
