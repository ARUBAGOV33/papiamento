## Rule
cu is also used as the fixed preposition of certain verbs and verbal expressions. The book gives a list of them that ends in "etc.", so the list is not closed.

## Source
Preposicion y Interheccion di Papiamento, 1.3.3 Cu, VI. Preposicion fiho, printed page 6.
"Ta uza cu tambe como preposicion fiho cu cierto verbo of expresion verbal:"

## Correct
- bringa cu
- baha cu
- pleita cu
- pusta cu
- pompa cu
- core cu
- cuminsa cu
- caba cu
- cuadra cu
- hari cu
- soña cu
- tene cuenta cu
- tene compasion cu
- tene pasenshi cu
- ta contento cu
- ta satisfecho cu

## Notes
- The page prints only this list, with no example sentences and no incorrect forms. It does not say that another preposition after these verbs is wrong, so this rule flags nothing; reviewers may want to raise the severity if a checker should suggest cu here.
- The old rule pack's example for this rule ("No duda di …") is the fixed preposition di; it belongs to RULE_PRE_DI_FIXED_001. The note on cu ne is RULE_PRE_CU_NE_001.
