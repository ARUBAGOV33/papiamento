# _templates/

Starter files. Copy one, then replace every value.

| Template | Use it to |
|---|---|
| `word-row.tsv` | Add a word to `lexicon/words/<LETTER>/words.tsv` (copy the row, not the header) |
| `rule.md` | Write a grammar rule in `grammar/<topic>/` |
| `source-card.md` | Register a new source in `sources/cards/` |
| `errata-row.tsv` | Log a typo or conflict found in a source PDF |
| `contributor-row.tsv` | Add yourself to `_meta/contributors.tsv` when you first contribute by pull request (copy the row, not the header; no email address) |
| `parallel-prompt-row.tsv` | Add an English or Spanish prompt to `corpus/parallel/prompts.tsv`. Check the hold-out first: see Parallel sentences in `_meta/conventions.md`. |
| `audit-row.tsv` | Log a random audit of a table in `_meta/audits.tsv` (copy the row, not the header; see the Audits section of `_meta/conventions.md`) |

The example values are placeholders, not data.
