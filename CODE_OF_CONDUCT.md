# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), by reference. The full text at that link is our Code of Conduct. This page summarises it and says how to report a problem.

## Summary

We want taking part in this project to be a good experience for everyone, whatever their age, background, education, language, nationality or identity.

Expected:

- Be kind and patient, especially with people who are new to GitHub.
- Respect different views and experience.
- Give and accept feedback on the work, not the person.
- Take responsibility for mistakes and learn from them.

Not accepted:

- Insults, harassment, or personal and political attacks.
- Sexual language or attention.
- Publishing someone's private information without their permission.
- Any other behaviour that would be inappropriate in a professional setting.

The Code of Conduct applies in this repository (issues, pull requests, reviews, discussions) and wherever someone represents the project.

## Disagreeing about language

Disagreement about spelling, meaning and grammar is normal and useful here. Settle it with sources and page numbers, following [GOVERNANCE.md](GOVERNANCE.md#disputes).

- Do not mock anyone's spelling or way of speaking.
- Papiamentu, as written in Curaçao and Bonaire, is a different standard, not a mistake. Treat its speakers with the same respect.

## Reporting a problem

Report privately to the maintainers (@ARUBAGOV33):

1. On the comment, issue or pull request, open the **...** menu and choose **Report content**.
2. Choose **Report to repository admins**. Only the repository admins see the report.

If the problem did not happen in something you can report this way, open an issue that mentions @ARUBAGOV33 and asks for a private contact. Do not put any details in the issue.

For serious abuse, you can also report the account to GitHub through the same **Report content** menu.

All reports are handled in confidence. Nobody will be penalised for making a report in good faith.

## Enforcement

The maintainers enforce the Code of Conduct, following the Covenant's enforcement guidelines. Depending on how serious the problem is, the response can be:

1. **Correction:** a private, written explanation of what went wrong.
2. **Warning:** a warning with consequences if the behaviour continues.
3. **Temporary ban:** no interaction with the project for a set time.
4. **Permanent ban:** no interaction with the project at all.

A maintainer who is involved in a report does not take part in deciding it.
